# Protección y Seguridad | Sistemas Operativos

Sitio web estático sobre la Unidad 6: Protección y Seguridad.

## Archivos

- `index.html`: página principal. Contiene el diseño, los estilos CSS y la interacción JavaScript. No requiere instalar dependencias.
- `.nojekyll`: evita que GitHub Pages procese el sitio con Jekyll.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `README.md` y `.nojekyll` a la raíz del repositorio.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera a que termine la publicación. GitHub mostrará la dirección del sitio en la misma sección de Pages.

## Personalización

Puedes modificar el contenido, los colores y los datos del alumno directamente en `index.html`.
